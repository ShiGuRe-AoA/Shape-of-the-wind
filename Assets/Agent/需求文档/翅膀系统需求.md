# 鸟翼输入状态控制器需求说明

## 1. 脚本目标

请新建一个用于管理鸟类玩家核心飞行输入数值与翅膀姿态表现的脚本。

该脚本的具体命名由 Agent 根据职责自动合理决定，但不要命名为 `PlayerInput`，避免与 Unity Input System 中的同名组件产生混淆。

推荐命名方向：

```txt id="z1b4yk"
BirdWingInputController.cs
BirdFlightInputController.cs
BirdWingStateController.cs
```

在没有特殊理由时，推荐使用：

```txt id="lsq50m"
BirdWingInputController.cs
```

该脚本不需要使用命名空间。请直接在全局作用域中声明类，保持临时项目代码简单直观。

## 2. 脚本定位

该脚本是“鸟的飞行输入状态控制器”。

它不是 Unity 输入读取器，不应直接读取键盘、手柄或 VR 手柄输入。它的职责是接收外部系统传入的鸟翼状态数据，统一存储、限制、推导，并将翅膀倾斜状态应用到左右翼骨骼上。

外部输入系统可以是当前的手柄模拟系统，也可以是未来的 VR 手柄系统。无论输入来源是什么，都必须通过本脚本提供的唯一入口函数写入数据。

## 3. 它应该负责什么

该脚本应该负责：

```txt id="c3kbbn"
存储左翼状态
存储右翼状态
存储整体翼展
存储整体倾角
存储每个翅膀的挥动速度
存储每个翅膀的倾斜情况
存储当前受到的风力
根据输入数据推导可直接给飞行控制器使用的值
根据翅膀倾角驱动左右翼骨骼局部旋转
```

该脚本不应该负责：

```txt id="qkjzba"
直接读取键盘输入
直接读取手柄输入
直接读取 VR 手柄输入
直接给 Rigidbody 施加力
直接计算风场
直接管理体力
直接控制摄像机
直接处理 UI
```

飞行控制器、风场系统、体力系统可以读取本脚本中的公开只读属性，但不应绕过入口函数直接改写内部字段。

## 4. 坐标空间约定

所有方向计算应以鸟模型水平放置时的朝向为基准。

约定：

```txt id="gptvub"
鸟模型水平放置时，模型正前方为正方向
鸟模型局部 Forward 表示鸟的前进方向
鸟模型局部 Up 表示鸟背部朝上的方向
鸟模型局部 Right 表示鸟身体右侧方向
```

推荐以 `transform` 的局部空间作为鸟自身空间。

也就是说：

```txt id="yplpaf"
transform.forward 表示鸟当前世界空间前方
transform.up 表示鸟当前世界空间上方
transform.right 表示鸟当前世界空间右方
```

如果外部输入传入的是世界空间数据，本脚本应在入口函数中将其转换为鸟自身局部空间下的数值，再存储和推导。

如果外部输入已经是局部空间数据，可以直接使用，但需要在入口函数参数注释中明确说明。

## 5. 单个翅膀状态结构

请用一个合理的数据结构概括每个翅膀的状态。

推荐定义一个可序列化结构：

```csharp id="g9v6xn"
[System.Serializable]
public struct WingState
{
    public float flapSpeed;
    public float tilt;
    public float normalizedFlapSpeed;
    public float normalizedTilt;
    public bool isDownFlapping;
    public float downFlapStrength;
}
```

字段含义：

```txt id="o9evbe"
flapSpeed
  翅膀挥动速度。
  向下挥动为正值，向上挥动为负值。
  主要用于控制主动升力和体力消耗。

tilt
  翅膀倾角。
  用于控制转向，也用于驱动翅膀骨骼局部旋转。

normalizedFlapSpeed
  归一化后的挥动速度，建议范围为 -1 到 1。

normalizedTilt
  归一化后的翅膀倾角，建议范围为 -1 到 1。

isDownFlapping
  当前是否正在有效向下拍翼。

downFlapStrength
  只统计向下拍翼强度，建议范围为 0 到 1。
```

结构应保持轻量，不要扩展成复杂输入系统。

## 6. 核心存储数值

该脚本至少需要存储以下数据，并提供公开只读属性。

```txt id="n6vkqz"
LeftWing
  左翼状态，类型为 WingState

RightWing
  右翼状态，类型为 WingState

WingSpan
  翼展，表示两翼展开程度，建议归一化到 0 到 1

BodyTilt
  整体倾角，用于表示鸟整体姿态或玩家整体输入倾向

WindForce
  当前受到的综合风力，类型为 Vector3，世界空间向量

AverageFlapSpeed
  左右翼挥动速度平均值

AverageDownFlapStrength
  左右翼有效向下拍翼强度平均值，建议范围为 0 到 1

WingTiltDifference
  左右翼倾角差值，用于转向计算

WingTiltAverage
  左右翼倾角平均值

HasInput
  当前是否已经接收过有效输入
```

其中部分参数可以从左右翼状态内部推导得出，但为了方便飞行控制器读取，可以作为只读属性暴露。

## 7. 唯一输入入口函数

外部系统必须只能通过一个统一入口函数写入核心输入数据。

推荐函数名：

```csharp id="ssnnky"
public void SetInput(BirdWingInputData inputData)
```

或者：

```csharp id="d1a9o6"
public void ApplyInput(BirdWingInputData inputData)
```

推荐新建一个数据结构：

```csharp id="r1r6xy"
[System.Serializable]
public struct BirdWingInputData
{
    public float leftFlapSpeed;
    public float rightFlapSpeed;
    public float leftWingTilt;
    public float rightWingTilt;
    public float wingSpan;
    public float bodyTilt;
    public Vector3 windForce;
}
```

所有外部输入系统，包括手柄模拟和未来 VR 手柄输入，都应该先整理出 `BirdWingInputData`，再调用 `SetInput` 或 `ApplyInput`。

不允许外部系统直接修改：

```txt id="uw6g8o"
leftWing
rightWing
wingSpan
bodyTilt
windForce
骨骼旋转结果
```

入口函数内部应负责：

```txt id="vj6h22"
接收原始输入
限制数值范围
更新左右翼状态
更新翼展
更新整体倾角
更新当前风力
计算派生参数
刷新翅膀骨骼姿态
标记 HasInput 为 true
```

## 8. 推荐数值范围

请在脚本中提供 Inspector 可调参数，用于限制和归一化输入。

推荐字段：

```csharp id="xxlpqk"
[SerializeField] private float maxAbsFlapSpeed = 5f;
[SerializeField] private float maxAbsWingTilt = 60f;
[SerializeField] private float maxAbsBodyTilt = 60f;
[SerializeField] private float wingBoneTiltMultiplier = 1f;
[SerializeField] private bool clampInputValues = true;
```

推荐范围：

```txt id="ece2al"
flapSpeed
  原始值允许为负或正。
  向下为正，向上为负。
  可通过 maxAbsFlapSpeed 归一化到 -1 到 1。

wingTilt
  单翼倾角，单位建议为度。
  可通过 maxAbsWingTilt 限制到 -maxAbsWingTilt 到 +maxAbsWingTilt。

bodyTilt
  整体倾角，单位建议为度。
  可通过 maxAbsBodyTilt 限制到 -maxAbsBodyTilt 到 +maxAbsBodyTilt。

wingSpan
  建议直接限制到 0 到 1。

windForce
  保持为世界空间 Vector3，不强制归一化。
  windForce.normalized 表示风向。
  windForce.magnitude 表示风力大小。
```

## 9. 派生参数计算规则

入口函数更新原始值后，应立即计算派生参数。

推荐计算：

```csharp id="m71aff"
AverageFlapSpeed = (LeftWing.flapSpeed + RightWing.flapSpeed) * 0.5f;

AverageDownFlapStrength =
    (Mathf.Max(0f, LeftWing.normalizedFlapSpeed) +
     Mathf.Max(0f, RightWing.normalizedFlapSpeed)) * 0.5f;

WingTiltDifference = RightWing.tilt - LeftWing.tilt;

WingTiltAverage = (LeftWing.tilt + RightWing.tilt) * 0.5f;
```

说明：

```txt id="m4f82w"
AverageFlapSpeed
  保留正负方向，可用于判断整体拍翼趋势。

AverageDownFlapStrength
  只统计向下拍翼强度，用于主动升力、体力消耗等系统。

WingTiltDifference
  主要用于转向。
  左右翼倾角差异越大，转向倾向越强。

WingTiltAverage
  可用于整体滑翔姿态或辅助飞行表现。
```

具体转向正负方向可以在飞行控制器中继续调整，本脚本只负责稳定提供差值。

## 10. 翅膀骨骼列表

本脚本需要持有两个 Transform 列表：

```csharp id="z08irs"
[SerializeField] private List<Transform> leftWingBones;
[SerializeField] private List<Transform> rightWingBones;
```

它们分别对应鸟模型的左翼骨骼和右翼骨骼。

列表顺序建议从靠近身体的根部骨骼到远离身体的翼尖骨骼。

如果列表为空，脚本不应报错中断运行，但应给出 Warning 或允许用户在 Inspector 中检查。

## 11. 翅膀骨骼初始旋转缓存

脚本应在 `Awake` 或 `Start` 中缓存每根翅膀骨骼的初始局部旋转。

推荐：

```csharp id="joqzu6"
private readonly List<Quaternion> leftWingInitialLocalRotations = new();
private readonly List<Quaternion> rightWingInitialLocalRotations = new();
```

应用倾角时，应基于初始局部旋转叠加，而不是每帧在当前旋转上继续叠加。

正确思路：

```txt id="fmhcg6"
最终局部旋转 = 初始局部旋转 * 本帧倾角旋转
```

不要写成：

```txt id="v4t8m6"
当前局部旋转 *= 本帧倾角旋转
```

否则会导致旋转不断累积，翅膀姿态逐渐失控。

## 12. 翅膀倾角作用方式

每个翅膀的倾角应叠加系数后作用到该翅膀每根骨骼的局部空间旋转角上，用于模拟翅膀弯曲。

推荐提供 Inspector 参数：

```csharp id="sbgwjf"
[SerializeField] private Vector3 leftWingTiltAxis = Vector3.forward;
[SerializeField] private Vector3 rightWingTiltAxis = Vector3.forward;
[SerializeField] private AnimationCurve boneTiltDistribution = AnimationCurve.Linear(0f, 0.4f, 1f, 1f);
[SerializeField] private float leftWingBoneSign = 1f;
[SerializeField] private float rightWingBoneSign = 1f;
```

说明：

```txt id="zef7xn"
leftWingTiltAxis
  左翼骨骼局部空间中的旋转轴。

rightWingTiltAxis
  右翼骨骼局部空间中的旋转轴。

boneTiltDistribution
  用于控制倾角在不同骨骼上的分布。
  x 表示骨骼序号归一化位置。
  y 表示该骨骼受到倾角影响的比例。

leftWingBoneSign / rightWingBoneSign
  用于处理左右翼骨骼方向不完全镜像时的旋转符号问题。
```

如果左翼有 5 根骨骼，可以让靠近身体的根部骨骼受影响较小，靠近翼尖的骨骼受影响较大。

这样能让翅膀产生更自然的弯曲，而不是所有骨骼都僵硬地转同一个角度。

## 13. 骨骼旋转计算建议

对每个骨骼应用旋转时，推荐逻辑：

```csharp id="mxu2sa"
float normalizedIndex = bones.Count <= 1 ? 1f : i / (float)(bones.Count - 1);
float distribution = boneTiltDistribution.Evaluate(normalizedIndex);
float angle = wingState.tilt * wingBoneTiltMultiplier * sideSign * distribution;
Quaternion offset = Quaternion.AngleAxis(angle, localAxis.normalized);
bone.localRotation = initialLocalRotation * offset;
```

需要分别处理左翼和右翼。

左右翼可能因为模型骨骼朝向不同，需要独立配置旋转轴或符号。

不要强行假设左右翼一定完全镜像。

## 14. 公开只读访问方式

其他系统需要读取飞行输入状态。

请提供公开只读属性，而不是 public 字段。

推荐：

```csharp id="qk1lon"
public WingState LeftWing => leftWing;
public WingState RightWing => rightWing;
public float WingSpan => wingSpan;
public float BodyTilt => bodyTilt;
public Vector3 WindForce => windForce;
public float AverageFlapSpeed => averageFlapSpeed;
public float AverageDownFlapStrength => averageDownFlapStrength;
public float WingTiltDifference => wingTiltDifference;
public float WingTiltAverage => wingTiltAverage;
public bool HasInput => hasInput;
```

内部字段使用 `[SerializeField] private` 或普通 `private`。

为了方便 Inspector 调试，核心字段可以 `[SerializeField] private`，但外部仍然不能直接修改。

## 16. 生命周期函数建议

推荐结构：

```txt id="rviv2c"

  缓存左右翼骨骼初始局部旋转
  检查必要引用

  唯一外部输入入口
  更新原始输入
  计算派生数值
  应用翅膀骨骼旋转

  限制 Inspector 参数范围
  保证 AnimationCurve 不为空
```

注意：本脚本不需要在 `Update` 中主动读取输入。

如果骨骼旋转只在输入更新时刷新，则入口函数内应用即可。

如果未来希望平滑过渡，可以再添加插值逻辑，但当前阶段优先保持直接、清楚、易调试。

## 18. 示例外部调用方式

外部输入系统应类似这样调用：

```csharp id="befmyn"
BirdWingInputData data = new BirdWingInputData
{
    leftFlapSpeed = leftFlapSpeed,
    rightFlapSpeed = rightFlapSpeed,
    leftWingTilt = leftWingTilt,
    rightWingTilt = rightWingTilt,
    wingSpan = wingSpan,
    bodyTilt = bodyTilt,
    windForce = currentWindForce
};

birdWingInputController.SetInput(data);
```

飞行控制器则只读取：

```csharp id="i6hcnx"
float lift = birdWingInputController.AverageDownFlapStrength;
float turn = birdWingInputController.WingTiltDifference;
float wingSpan = birdWingInputController.WingSpan;
Vector3 wind = birdWingInputController.WindForce;
```

飞行控制器不应直接改写鸟翼输入状态控制器的内部字段。
